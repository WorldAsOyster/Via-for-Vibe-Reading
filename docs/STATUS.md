# 当前状态 · 0.1.0-alpha.8

本仓库是 Via 的本机 Markdown 产品线。Windows Electron 主窗口、Typora 独立侧栏、本机持久化、DeepSeek/OpenAI 接口、邮箱认证接口和每日复盘工作流已实现。

每日复盘由原问答生成最多6题，应用验证原文摘录并确定性评分；模型提供巩固建议和最多3篇原生搜索引用。当前没有精选知识库。提醒需要应用运行。

本机开发工作区已通过50项测试及安装、覆盖安装和卸载保留数据检查。这50项包含历史多来源模块测试。公开源码已通过38项适用测试与真实main/preload原生回归，验证示例初始化、新增批注持久化、原文不变和复盘恢复；不包含浏览器扩展和云同步实现。

尚待验收：用户配置密钥后的真实模型生成/联网推荐、真实邮箱送达、干净 Windows 机器以及多屏/多窗口场景。当前认证环境为开发环境，安装包未签名，不能视为正式稳定版。

Windows x64 安装包已发布为 v0.1.0-alpha.8 预发布版本，附使用说明与 SHA-256 校验和。已有本地 alpha.8 安装包来自先前构建；公开源码另整理了反馈链接和帮助素材，重新构建时以本仓库文件为准。

批注唯一事实源是本机 DocumentStore；没有自动云同步、自动执行待办、自动投递消息或原文自动改写。文件移动/改名后的无条件恢复与原文精确高亮也不在当前承诺范围。
