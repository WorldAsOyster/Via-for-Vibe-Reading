# Via 快速开始

当前支持 Windows x64 和 Typora，本机 Markdown 是唯一正式阅读来源。

## 运行与安装

源码需要 Node.js 和 npm。安装依赖后运行真实桌面应用：

```powershell
cd typora-app
npm ci
npm run desktop
```

主窗口关闭后应用留在托盘；双击图标恢复窗口，右键选择「退出 Via」完全退出。

Windows 安装包可以在同一目录执行 `npm run build:win` 生成。输出位于 `dist/v0.1.0-alpha.8-shipping/`，包含安装程序、便携 ZIP、校验和与构建清单。安装后的程序无需 Node.js。已有输出不会被脚本覆盖。

## 第一次使用

1. 在「设置 → AI 连接」选择 DeepSeek 或 OpenAI，保存自己的 API 密钥。密钥在本机使用系统能力加密，模型调用可能产生费用。
2. 资料库内附两份安克产品策划/技术评审文档，每篇10条明确标识的示例批注。文件首次复制到 `%APPDATA%/via-local-markdown/示例文档`，可用 Typora 打开。用户修改和移除的示例不会在重启后被覆盖或恢复。
3. 在「设置 → 连接器管理」复制 Typora 自定义命令。请用 App 生成的本机命令，避免复制他人的安装路径。
4. Typora「文件 → 导出 → 导出设置」，新增「自定义」，命名为 **问 Via**，粘贴命令，选择「不选择导出路径」。
5. Typora「通用 → 打开高级设置」，在 `conf.user.json` 的 `keyBinding` 中加入 `"问 Via": "Ctrl+Q"`。注意逗号和原有配置；保存后重启 Typora。命令名及快捷键须与 Via 设置一致。
6. 保存 Markdown，选中文字后按 `Ctrl+Q`。首次关联可能出现一次 Typora 的导出提示；后续同一资料可直接恢复侧栏。取不到选区时可以手动粘贴引用。

## 阅读、协作与复盘

- `@Via` 触发模型回答。回复同一批注可以继续追问；收藏保留完整问答。
- `@Codex`、`@Claude`、`@其他AI` 或 `@同事` 形成**本机待办**，不会自动发送或执行。主窗口按对象/资料整理并导出；按人导出可选批注 Markdown 或原文+该人批注 PDF。
- 首页生成指定日期的复盘，依据当天有引用、已回答的问题最多生成6道选择题。提交后评分并给出巩固建议，按公开概念搜索最多3篇延伸阅读；取不到可信来源时不推荐文章。
- 日期格子可恢复历史问答和答题。提醒仅在应用运行时触发，重新启动会补查当天提醒。

## 账号与数据

可以使用邮箱注册、验证码/密码登录和找回密码，也可以先在本机使用。当前账号连接 CloudBase **开发环境**，真实邮件送达仍待验收。登录不启用阅读记录云同步。

批注、待办、收藏和复盘保存在 `%APPDATA%/via-local-markdown`，与原 Markdown 分开。原文件不会被自动改写；卸载保留本机数据。向模型提问/生成复盘会发送相关引用和上下文；文章搜索只发送受控公开概念标签。

## 开发检查

```powershell
cd typora-app
npm test
npx electron test/native-app-smoke.cjs
```

自动测试使用模拟模型验证规则；原生 smoke 使用隔离的本机数据。真实模型检查 `npx electron test/live-review.cjs` 使用在 App 配置的密钥，并可能产生费用。请勿提交密钥、会话或测试数据。

纯前端展示可运行 `node frontend/build.cjs`，在生成的 `../demo/` 内安装依赖并构建。它使用预制回答及浏览器本地状态，与真实桌面程序区分。
